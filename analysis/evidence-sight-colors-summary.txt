Sight test and colour tables, live evidence, Altirra 4.40, Atari 800 NTSC, Rev B OS, 48K, 800 % speed.
Test aids (emulated machine only): the game is started by jumping to its start-game code, ghosts do not kill Pac-Man, and for the sight run Pac-Man is moved to a new junction row every 128 frames and a new column every 1,280 frames.

=== Sight test (GhostSeesPacMan $BA19) against tools/sight_model.py, a model built from the ROM bytes (tools/altirra_sight.cmd, 180 s of wall time) ===
6129 lines, 6069 same-row/column sight tests, 51 ended in chase (SIGHT_YES)
model == game on 6069 of 6069 tests (0 disagreements)
model decisions by kind: COL sees=False: 1063, COL sees=True: 22, ROW sees=False: 4955, ROW sees=True: 29
Ghost 2 rule (reacts only when RTCLOK2 bit 7 is clear), live: of the tests where ghost 2's geometry and direction said "sees": chase in 13 of 13 with RTCLOK2 < $80, no chase in 137 of 137 with RTCLOK2 >= $80.
Other ghosts (0, 1, 3) with positive geometry: chase in 17 of 17 (RTCLOK2 < $80) and 21 of 21 (RTCLOK2 >= $80).
Data layout, static: the offset tables hold exactly the start offsets of the five x lists and of the five y lists (vertical offsets mirror-symmetric); the code reads the offset tables as if they were the lists.
Against the maze (junction table connectivity, pairs of real junctions on one row or column): applying the offsets would agree on 732 of 746 horizontal and 648 of 728 vertical pairs; the shipped code agrees on 478 and 360.
