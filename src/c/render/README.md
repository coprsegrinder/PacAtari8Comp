# render/ - the picture of the screen from the World (stage 80b, docs/42, 35, 47)

`render.[ch]`: ANTIC (display list, modes 2, 4, 6, 7, the display-list interrupts of the game's two handlers) and GTIA (player-missile objects, PRIOR, colour registers) as a function of the World,
to a 384 x 240 picture of colour bytes; `palette.[ch]` (generated by `tools/make_c_palette.py` from `analysis/palette-ntsc-measured.txt`, measured from Altirra by `tools/measure_palette.py`):
the NTSC palette, 128 colours. NTSC only. Checked against the real captures by `tests/test_render.py`.

Checked by `tests/test_render.py` and `tools/check_render_shots.py` against 12 real captures (C-114). `tests/render_check` draws one World image for the checkers.
