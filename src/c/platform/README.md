# platform/ - the Platform layer (docs/45, tools/platform_iface.py): the 14 inputs, clock, RANDOM, collisions in; the frame's outputs out. **fs.[ch]** (stage 75b): the only door to files - relative paths under the main folder, 44 kinds of escaping path refused, links refused (`tests/fs_sandbox.c`); **hal.h** (the 14 inputs as a table of functions), **hal_scripted.[ch]** (the scripted platform: stick script, clock, RANDOM, collisions none / fixed / the GTIA model, call counters), **pokey_random.[ch]** (the RANDOM model of decision D1) (stage 77b); the keyboard / pad / window / audio shell comes with stage 80.

**timer.[ch]** (stage 88): `pm_time_ns()`, a monotonic clock in nanoseconds (QueryPerformanceCounter, clock_gettime); the shell's `--time` is its only user; nothing in the game depends on it.
