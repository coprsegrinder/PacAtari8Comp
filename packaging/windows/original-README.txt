You do not need to put anything in this folder.

The first time the program starts it asks for your own Pac-Man (Atari 8-bit)
cartridge ROM (NTSC, 8,192 bytes), reads it once, and makes the game's data files
in the folder resources. If you prefer, you can put the ROM here as Pac-Man.rom
before the first start and it will be used without asking.

The ROM is not part of this program and is not included.
