## 3. The structures

The original keeps each kind of object as a **structure of arrays** (the x of the five entities, then their y, ...), indexed by X. The port keeps the original layout in the `World` (so the state can be compared byte for byte) and names the structures here (`30` section 7 has the proposed array-of-structures C layout). The indexes: **ghost** 0-3 (0 red, 1 pink, 2 green, 3 gold), **entity** 0-4 (the four ghosts and Pac-Man as 4: the player page of each), **player** 0-1.

### `Entity` x 5

the five moving objects: ghosts 0-3 (index 0 red, 1 pink, 2 green, 3 gold: the colour order of `ColorsGame`) and Pac-Man (index 4). The index is the player page: ghost g draws in page $24+g, Pac-Man in the missile page $23.

| Member | C type | Variable | What it is |
|---|---|---|---|
| `x` | uint8_t | `EntityX` | horizontal position in colour clocks; the tunnel wraps $2A <-> $CA |
| `y` | uint8_t | `EntityY` | vertical position in scan lines = the row of the player page where the picture starts |
| `dir` | uint8_t | `EntityDir` | 1 up, 2 down, 4 left, 8 right (a bit mask: the same values index JunctionExits and the reverse tables) |
| `delay_cycle` | uint8_t | `MoveDelayCycle` | position in the four-step speed-pacing cycle |
| `delay_count` | uint8_t | `MoveDelayCount` | frames left until the next step |

## 4. Lifetimes: what each event clears

| From | To | Class | What clears it |
|---|---|---|---|
| `$18` | `$1F` | start-up | cleared once by the cold start (`Start` $A395, X = $27..0 stores A = 0 in $18-$3F) |
| `$20` | `$3F` | game | cleared at every start and restart of the game (`$A47B`: X = $1F..0 stores 0 in $20-$3F), then set by NewGameInit / ClearPlayerCounters |
| `$80` | `$FF` | board | cleared by InitBoard (`$ADB4`: X = $7F..0 stores 0 in $80-$FF; called by Start, FrameDispatch and TurnControl: the first board, a new board, a new life, a turn switch); $80-$93 are then loaded from `ZeroPageInit80`, `MoveDelayCount` and `GhostTimer`[1..3] are set |

The reset / keep / compute matrices of each event (`InitBoard` 114 constants, the restart 144 bytes, the turn control, `AdvanceLevel`, a ghost eaten, a power pellet) are in `43`; which zero-page bytes are state at all (144 of 256, found by experiment) is `43` section 2.

## 7. The lookup tables
