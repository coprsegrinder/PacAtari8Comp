## 5. What is not correlated

- **The port, in part.** OV-02 closed in stage 87: the C port equals the ROM frame by frame (`52`, `53`); what is not covered is OV-71 (routine call counts only for the vertical-blank handler, not for the key loop, the new-game sequence and the display-list interrupts), OV-72 (macOS, MSVC, 32-bit, big-endian, ARM; `54`) and the limits of `53` section 6 (samples of up to 12,000 frames, one board change at most).
- **The five instructions never executed live** are dead code of the original (`32`, OV-59, C-62): they were run by the model comparisons only.
- **Real hardware**, **a human playing every situation**: documented limits (`OPEN-VERIFICATION.md`).
